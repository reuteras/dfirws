# Ares

**Category:** Utilities / Cryptography

**Homepage:** <https://github.com/bee-san/Ares>

**Vendor:** bee-san

**License:** MIT

**Source:** GitHub Release

**Profiles:** Full, Basic

**File Extensions:** `.exe`, `.dll`

**Tags:** malware-analysis, pe-analysis

Automated decoding of encrypted text without knowing the key or ciphers used

## Tips
Tries many decoders and ciphers automatically and stops when readable output appears. Use -t to raise the timeout for deeper searches; chepy and CyberChef are the manual alternatives.

## Usage
ares '<encoded text>'
