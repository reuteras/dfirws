PowerSponse is a PowerShell module focused on targeted containment and remediation during incident response.

## Tips
Containment and remediation module for remote Windows hosts. It needs network access to the targets, so run it from the network sandbox or from the target environment.

## Usage
Import-Module C:\git\PowerSponse\PowerSponse.psd1 ; Get-Help Invoke-PowerSponse
