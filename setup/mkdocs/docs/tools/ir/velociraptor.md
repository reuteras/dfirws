# Velociraptor

**Category:** IR

**Homepage:** <https://docs.velociraptor.app/>

**Vendor:** Velocidex


**Source:** GitHub Release

**Profiles:** Full (not included in Basic profile)

**File Extensions:** `.json`, `.csv`

**Tags:** incident-response, forensics, endpoint-detection

Velociraptor is an advanced digital forensic and incident response tool that enhances your visibility into your endpoints.

## Tips
Excluded from the Basic profile. Use 'velociraptor.exe gui' for a local instance, or run artifacts offline against a directory with 'velociraptor.exe artifacts collect' and the offline collector.

## Usage
velociraptor.exe gui
