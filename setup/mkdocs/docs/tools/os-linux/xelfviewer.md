# XELFViewer

**Category:** OS / Linux

**Homepage:** <http://ntinfo.biz>

**Vendor:** horsicq

**License:** MIT

**Source:** GitHub Release

**Profiles:** Full, Basic

**File Extensions:** `.elf`, `.mach-o`

**Tags:** reverse-engineering, elf-analysis

ELF file viewer/editor for Windows, Linux and MacOS.

## Tips
Inspect ELF headers, sections, symbols and entropy on Windows. Same family as Detect It Easy; Elfparser-ng is the alternative.

## Usage
GUI: start from the desktop shortcut and open an ELF file.
