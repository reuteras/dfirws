# Elfparser-ng

**Category:** OS / Linux

**Homepage:** <https://github.com/mentebinaria/elfparser-ng>

**Vendor:** mentebinaria


**Source:** GitHub Release

**Profiles:** Full, Basic

**File Extensions:** `.elf`, `.so`

**Tags:** reverse-engineering, elf-analysis, linux

Multiplatform CLI and GUI tool to show information about ELF files.

## Tips
Shows ELF headers, sections, symbols and a capability score for Linux binaries. XELFViewer is the alternative.

## Usage
GUI: start from the desktop shortcut and open an ELF file.
