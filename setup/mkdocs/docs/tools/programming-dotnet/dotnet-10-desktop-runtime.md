# DotNet 10 Desktop Runtime

**Category:** Programming / dotNET

**Homepage:** <https://dotnet.microsoft.com>

**Vendor:** Microsoft Corporation

**License:** MIT

**Source:** Winget

**Profiles:** Full, Basic

**Tags:** dotnet

The .NET Desktop Runtime enables you to run existing Windows desktop applications. This release includes the .NET Runtime; you don't need to install it separately. Version 10.0.

## Tips
Required by the current Eric Zimmerman tools and other .NET 10 applications. Check installed runtimes with 'dotnet --list-runtimes'.

## Usage
Installed silently during sandbox start; nothing to run.
