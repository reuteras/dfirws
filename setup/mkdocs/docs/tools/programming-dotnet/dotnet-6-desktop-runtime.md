# DotNet 6 Desktop Runtime

**Category:** Programming / dotNET

**Homepage:** <https://www.nsa.gov/ghidra>

**Vendor:** NationalSecurityAgency

**License:** Apache-2.0

**Source:** Installer

**Profiles:** Full, Basic

**Tags:** dotnet

The .NET Desktop Runtime enables you to run existing Windows desktop applications. This release includes the .NET Runtime; you don't need to install it separately. Version 6.0.

## Tips
Required by tools still built for .NET 6. Check which runtimes are present with 'dotnet --list-runtimes'.

## Usage
Installed silently during sandbox start; nothing to run.
