Carve file metadata from NTFS index ($I30) attributes

## Tips
Carves file names, sizes and timestamps from NTFS index (I30) slack, recovering entries for deleted files that are gone from the MFT. Works on raw images, E01 and extracted MFT files.

## Usage
INDXRipper.exe <image or MFT file> output.csv
