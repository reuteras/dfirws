$MFT directory tree reconstruction & FILE record info

## Tips
Rebuilds the directory tree from the MFT and shows FILE record details, including STANDARD_INFORMATION and FILE_NAME timestamps for timestomping checks.

## Usage
GUI: start from the desktop shortcut and open an MFT file.
