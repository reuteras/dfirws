Attack Graph Visualizer and Explorer (Active Directory) ...Who's *really* Domain Admin?

## Tips
Collect from a domain joined host or the network sandbox, then run analyze in the sandbox to open the attack graph UI in a browser. Excluded from the Basic profile.

## Usage
adalanche.exe collect activedirectory --domain <domain> ; adalanche.exe analyze
