# DitExplorer

**Category:** OS / Windows / Active Directory

**Homepage:** <https://github.com/trustedsec/DitExplorer>

**Vendor:** trustedsec

**License:** GPL-3.0

**Source:** GitHub Release

**Profiles:** Full, Basic

**File Extensions:** `.dit`

**Tags:** windows, network-analysis, forensics

Tool for viewing NTDS.dit Active Directory database files.

## Tips
Browse users, groups, computers and attributes in an offline NTDS.dit. Copy the file from a shadow copy or image first.

## Usage
GUI: start from the desktop shortcut and open an NTDS.dit file.
