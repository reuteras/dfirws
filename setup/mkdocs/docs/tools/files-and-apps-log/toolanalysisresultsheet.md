# ToolAnalysisResultSheet

**Category:** Files and apps / Log

**Homepage:** <https://github.com/JPCERTCC/ToolAnalysisResultSheet>

**Vendor:** JPCERTCC


**Source:** Git

**Profiles:** Full, Basic

**File Extensions:** `.evtx`

**Tags:** forensics, documentation, security-testing

This repository summarizes the results of examining logs recorded in Windows upon execution of the 49 tools which are likely to be used by the attacker that has infiltrated a network.

## Tips
Reference material from JPCERT describing the event log, registry and file system traces left by 49 common attacker tools (PsExec, mimikatz, wmic and others). Use it to know which artifacts to look for when a tool is suspected.
