Takajō (鷹匠) is a Hayabusa results analyzer.

## Tips
Post processes hayabusa JSONL output: automagic runs every analyser, or use timeline-logon, timeline-suspicious-processes, list-domains and extract-vt individually.

## Usage
takajo.exe automagic -t <hayabusa jsonl> -o <output dir>
