# LUMEN

**Category:** Files and apps / Log

**Source:** npm

**Profiles:** Full, Basic

**File Extensions:** `.evtx`

**Tags:** log-analysis, event-log, forensics, visualization

Your Browser-based EVTX Companion.

## Tips
Browser based EVTX viewer for quick visual review and filtering of a few logs. Use hayabusa, chainsaw or EventHawk for bulk analysis. Excluded from the Basic profile.

## Usage
Start from the desktop shortcut (lumen.ps1) and open EVTX files in the browser.
