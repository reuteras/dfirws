# fx

**Category:** Files and apps / Log

**Homepage:** <https://fx.wtf>

**Vendor:** antonmedv

**License:** MIT

**Source:** GitHub Release

**Profiles:** Full, Basic

**File Extensions:** `.json`, `.jsonl`

**Tags:** json, data-processing, visualization

fx is a terminal JSON viewer and processor.

## Tips
Interactive JSON viewer: use the arrow keys to expand, / to search and JavaScript expressions to filter, for example fx data.json '.items.map(x => x.name)'.

## Usage
fx file.json
