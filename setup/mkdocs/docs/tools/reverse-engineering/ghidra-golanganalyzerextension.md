# Ghidra GolangAnalyzerExtension

**Category:** Reverse Engineering

**Homepage:** <https://github.com/mooncat-greenpy/Ghidra_GolangAnalyzerExtension>

**Vendor:** mooncat-greenpy


**Source:** GitHub Release

**Profiles:** Full, Basic

**File Extensions:** `.exe`, `.elf`

**Tags:** reverse-engineering, golang

GoLang extension for Ghidra.

## Tips
Recovers Go function names, types and strings in Ghidra. Install it, then re-analyse the Go binary with the analyzer enabled.

## Usage
Install in Ghidra via File -> Install Extensions and restart.
