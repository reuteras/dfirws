# ghidrecomp

**Category:** Reverse Engineering

**Source:** Python

**Profiles:** Full, Basic

**File Extensions:** `.exe`, `.dll`, `.elf`

**Tags:** reverse-engineering, decompiler

Python Command-Line Ghidra Decomplier.

## Tips
Headless decompilation of every function with Ghidra into text files; requires Ghidra and Java. Use --filter to limit functions and -o for the output directory.

## Usage
ghidrecomp <binary>
