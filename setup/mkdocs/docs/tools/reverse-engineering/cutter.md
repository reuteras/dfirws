# Cutter

**Category:** Reverse Engineering

**Homepage:** <https://cutter.re>

**Vendor:** rizinorg

**License:** GPL-3.0

**Source:** GitHub Release

**Profiles:** Full (not included in Basic profile)

**File Extensions:** `.exe`, `.dll`, `.elf`, `.bin`, `.so`, `.dylib`

**Tags:** reverse-engineering, disassembler, decompiler, gui

Cutter is a Qt and C++ GUI powered by Rizin that provides an intuitive interface for reverse engineering and analyzing binaries across multiple platforms.

## Tips
Rizin based GUI with decompiler, graph view and plugin support (radare2-deep-graph, cutterref, cutter-jupyter). Excluded from the Basic profile.

## Usage
GUI: start from the desktop shortcut and open a binary.
