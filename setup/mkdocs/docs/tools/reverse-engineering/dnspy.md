# dnSpy

**Category:** Reverse Engineering

**Homepage:** <https://github.com/dnSpyEx/dnSpy>

**Vendor:** dnSpyEx

**License:** GPL-3.0

**Source:** GitHub Release

**Profiles:** Full, Basic

**Tags:** dotnet, debugging, reverse-engineering

dnSpy is a .NET debugger and decompiler. It can be used to analyze and debug .NET applications, including malware.

## Tips
Decompile, edit and debug .NET assemblies. Use the 32 bit build for x86 assemblies when debugging; for obfuscated code run de4dot first or compare with ILSpy output.

## Usage
GUI: start dnSpy (32 or 64 bit) and open a .NET assembly.
