# x64dbg

**Category:** Reverse Engineering

**Homepage:** <http://x64dbg.com>

**Vendor:** x64dbg


**Source:** GitHub Release

**Profiles:** Full, Basic

**File Extensions:** `.exe`, `.dll`

**Tags:** reverse-engineering, debugging, dynamic-analysis

An open-source user mode debugger for Windows. Optimized for reverse engineering and malware analysis.

## Tips
Install on demand. User mode debugger for x86 and x64; unpack samples by breaking on VirtualAlloc and VirtualProtect and dump the result with the Scylla plugin.

## Usage
dfirws-install.ps1 -X64dbg
