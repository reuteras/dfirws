A multi-arch assembly REPL and emulator for your command line.

## Tips
Interactive assembly REPL with emulation for x86, x64, ARM and other architectures. Ideal for testing shellcode snippets; type /help inside the REPL for the command list.

## Usage
scare.ps1 -a x64
