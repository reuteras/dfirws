Code Coverage Exploration Plugin for Ghidra.

## Tips
Visualises code coverage data (DynamoRIO drcov, Pin) inside Ghidra so you can see which code paths a sample executed.

## Usage
Install in Ghidra via File -> Install Extensions and restart.
