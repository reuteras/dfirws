# Iaito

**Category:** Reverse Engineering

**Homepage:** <https://github.com/radareorg/iaito>

**Vendor:** radareorg

**License:** GPL-3.0

**Source:** GitHub Release

**Profiles:** Full, Basic

**File Extensions:** `.exe`, `.dll`, `.elf`, `.bin`, `.so`

**Tags:** reverse-engineering, disassembler, gui

iaito is the official graphical interface for radare2, a libre reverse engineering framework.

## Tips
Official radare2 GUI with graph views and the decompiler. Use it when you prefer clicking over the radare2 command line; Cutter is the Rizin based alternative.

## Usage
GUI: start from the desktop shortcut and open a binary.
