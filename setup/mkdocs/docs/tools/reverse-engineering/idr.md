Interactive Delphi Reconstructor

## Tips
Load the knowledge base (.kb) matching the Delphi version to recover class names, forms and event handlers. Export the map file and import it into Ghidra or IDA to name functions.

## Usage
GUI: run C:\git\IDR\bin\Idr.exe and open a Delphi executable.
