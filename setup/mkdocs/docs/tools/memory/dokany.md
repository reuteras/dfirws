# Dokany

**Category:** Memory

**Homepage:** <http://dokan-dev.github.io>

**Source:** GitHub Release

**Profiles:** Full (not included in Basic profile)

**Tags:** filesystem, disk-forensics

User mode file system library for windows with FUSE Wrapper

## Tips
User mode file system driver needed by MemProcFS to mount memory images as a drive letter. Install it before running MemProcFS with the mount option.

## Usage
dfirws-install.ps1 -Dokany
