# minidump

**Category:** Memory

**Source:** Python

**Profiles:** Full, Basic

**File Extensions:** `.dmp`

**Tags:** memory-forensics, windows

Python library to parse Windows minidump file format.

## Tips
Parses Windows minidump files and lists modules, threads and memory regions. Used by pypykatz for LSASS dumps.

## Usage
minidump <file.dmp>
