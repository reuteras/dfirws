# mboxviewer

**Category:** Files and apps / Email

**Homepage:** <https://github.com/eneam/mboxviewer>

**Vendor:** eneam


**Source:** GitHub Release

**Profiles:** Full, Basic

**File Extensions:** `.mbox`, `.eml`

**Tags:** email, forensics

A small but powerful app for viewing MBOX files.

## Tips
Browse, search and export messages and attachments from MBOX mail archives (Thunderbird, Google Takeout). Large archives are indexed on first open.

## Usage
GUI: start from the desktop shortcut and open an MBOX file.
