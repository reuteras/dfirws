# extract-msg

**Category:** Files and apps / Email

**Source:** Python

**Profiles:** Full, Basic

**File Extensions:** `.msg`

**Tags:** email, data-extraction

Extracts emails and attachments saved in Microsoft Outlook's .msg files

## Tips
Extracts body, headers and attachments from Outlook MSG files into a folder. Use --json for machine readable output, --raw to keep original encodings and --out-name to set the folder.

## Usage
extract_msg <file.msg>
