**File Extensions:** `.eml`

**Tags:** email, forensics, phishing

With EmailAnalyzer you can analyze your suspicious emails. You can extract headers, links, and hashes from the .eml file and you can generate reports.

## Tips
Extracts headers, links, attachments and hashes from EML files and can write an HTML report with -o. Pair it with emldump.py from the Didier Stevens suite for deeper MIME inspection.

## Usage
python C:\git\EmailAnalyzer\email-analyzer.py -f <file.eml> -H -d -l -a
