# SmartDeblur

**Category:** Utilities / Media

**Homepage:** <https://github.com/y-vladimir/smartdeblur>

**Vendor:** Y. Vladimir

**License:** GPL-3

**Source:** Git

**Profiles:** Full, Basic

**Tags:** image-restoration, forensics

SmartDeblur is a tool for restoring unfocused and blurred images. It can be used to recover details from images that are out of focus or have motion blur.

## Tips
Try the Out of Focus preset first and increase the radius slowly; use the Motion Blur mode only when the blur has a clear direction. Useful for recovering text from blurred screenshots and photos.

## Usage
GUI: start from the desktop shortcut and open a blurred image.
