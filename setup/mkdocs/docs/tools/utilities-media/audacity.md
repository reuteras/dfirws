# Audacity

**Category:** Utilities / Media

**Homepage:** <https://wiki.audacityteam.org/wiki/For_Developers>

**Vendor:** audacity


**Source:** GitHub Release

**Profiles:** Full (not included in Basic profile)

**File Extensions:** `.wav`, `.mp3`, `.flac`, `.ogg`, `.aiff`

**Tags:** audio, steganography

Audacity is a free and open-source audio editing software.

## Tips
Use the spectrogram view to find hidden data in audio (CTF steganography) and to review recordings. Export with File -> Export Audio.

## Usage
GUI: start from the desktop shortcut and open an audio file.
