**Category:** Utilities / Media

**File Extensions:** `.E01`, `.vhd`, `.vhdx`, `.vmdk`, `.tar`, `.zip`

**Tags:** triage, metadata, hashing

GLEAPP is a triage toolkit for large sets of images and video. It hashes and de-duplicates media, reads metadata, extracts video key frames, matches known-hash lists and opens a local review gallery with find-similar.

## Tips
Accepts folders, extraction archives and disk images. Create cases under Desktop\readwrite since other folders in the sandbox are lost when it closes. Use the browser shortcut if the GLEAPP window fails to open, it does not need WebView2. No known-hash lists are included.

## Usage
Start GLEAPP from the shortcut and create a case in the launcher. The Windows build has no command line, only GLEAPP.exe and GLEAPP.exe web. Starting it takes a while since it unpacks itself to a temporary folder.
