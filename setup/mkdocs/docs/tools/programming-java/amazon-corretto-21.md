Amazon Corretto is a no-cost, multiplatform, production-ready distribution of the Open Java Development Kit (OpenJDK).

## Tips
Corretto 21 is the default Java runtime used by Ghidra, jd-gui, Recaf, bytecode-viewer, MsgViewer and other Java tools. Run 'java -version' to confirm which runtime is active on PATH.
