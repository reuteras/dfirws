Wireshark Plugin for traffic-matrix visualization.

## Tips
Wireshark must be installed first with dfirws-install.ps1 -Wireshark. Once loaded, the traffic matrix visualisation is available in the Wireshark Tools menu.

## Usage
Copy the Lua plugin into the Wireshark plugins directory and reload Lua plugins (Analyze -> Reload Lua Plugins).
