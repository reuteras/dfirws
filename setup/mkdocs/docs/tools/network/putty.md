# PuTTY

**Category:** Network

**Homepage:** <https://www.chiark.greenend.org.uk/~sgtatham/putty/>

**Vendor:** Simon Tatham

**License:** [MIT](https://www.chiark.greenend.org.uk/~sgtatham/putty/licence.html)

**Source:** Winget

**Profiles:** Full (not included in Basic profile)

**Tags:** network, terminal

PuTTY is a free and open-source terminal emulator and SSH client for Windows. It is used to connect to remote systems via SSH, Telnet, and other protocols.

## Tips
Install on demand for SSH and serial connections from the network sandbox; plink and pscp come with it for scripted transfers.

## Usage
dfirws-install.ps1 -PuTTY
