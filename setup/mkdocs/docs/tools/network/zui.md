# Zui

**Category:** Network

**Homepage:** <https://www.brimdata.io/download/>

**Vendor:** brimdata


**Source:** GitHub Release

**Profiles:** Full (not included in Basic profile)

**File Extensions:** `.pcap`, `.pcapng`, `.zng`

**Tags:** network-analysis, pcap

Zui is a tool for analyzing network traffic. It can read pcap and zng files and provides a powerful query language for analyzing the data.

## Tips
Install on demand. Loads PCAP (through Zeek), JSON and CSV and lets you query with the Zed language. Good for a first overview of a large capture.

## Usage
dfirws-install.ps1 -Zui
