# Tailscale

**Category:** Network

**Homepage:** <https://tailscale.com/download>

**Vendor:** Tailscale Inc.

**License:** [BSD-3-Clause](https://github.com/tailscale/tailscale/blob/HEAD/LICENSE)

**Source:** Winget

**Profiles:** Full (not included in Basic profile)

**Tags:** network

Tailscale is a modern VPN solution that allows you to create secure, private networks between your devices. It is designed to be easy to use and can be used for remote access, secure file sharing, and connecting devices across different networks.

## Tips
Joins the sandbox to a tailnet for transferring evidence securely between machines; only works in the network enabled sandbox.

## Usage
Install on demand and run 'tailscale up' in the network sandbox.
