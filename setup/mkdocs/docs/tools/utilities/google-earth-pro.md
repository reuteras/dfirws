# Google Earth Pro

**Category:** Utilities

**Homepage:** <https://www.google.com/earth/about/>

**Vendor:** Google

**License:** [Freeware](https://www.google.com/help/terms_maps/)

**Source:** Winget

**Profiles:** Full (not included in Basic profile)

**File Extensions:** `.kml`, `.kmz`

**Tags:** geolocation, osint, visualization

Google Earth Pro is a tool for viewing satellite imagery, maps, and geographic information. It can be used for geolocation analysis, visualizing data, and exploring geographic features.

## Tips
Install on demand to plot coordinates from EXIF data or GeoIP results; map tiles need the network sandbox.

## Usage
dfirws-install.ps1 -GoogleEarth
