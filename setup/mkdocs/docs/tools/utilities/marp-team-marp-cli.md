A CLI interface for Marp and Marpit based converters. Markdown presentations.

## Tips
Converts Markdown to slide decks (HTML, PDF, PPTX) for presenting findings. Use --html to allow inline HTML and --theme for custom styling.

## Usage
marp slides.md -o slides.pdf
