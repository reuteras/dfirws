**Profiles:** Full, Basic

**Tags:** terminal, shell

Oh My Posh is a customizable prompt for PowerShell and other shells. It allows you to create beautiful and functional command-line prompts with themes and customizations.

## Tips
Enable with WSDFIR_OHMYPOSH set to Yes in the configuration to get a themed prompt with git and venv information. Cosmetic only.

## Usage
dfirws-install.ps1 -OhMyPosh
