# markitdown

**Category:** Utilities

**Source:** Python

**Profiles:** Full, Basic

**File Extensions:** `.docx`, `.xlsx`, `.pptx`, `.pdf`, `.html`

**Tags:** conversion, markdown, data-extraction, office

Utility tool for converting various files to Markdown.

## Tips
Converts PDF, Office, HTML, images and audio to Markdown for reading and for feeding LLMs. Use it to turn documents into notes for Obsidian.

## Usage
markitdown <file> -o out.md
