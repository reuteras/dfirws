# Dependencies

**Category:** Utilities

**Homepage:** <https://github.com/lucasg/Dependencies>

**Vendor:** Lucas Gabriel

**License:** MIT

**Source:** GitHub Release

**Profiles:** Full, Basic

**File Extensions:** `.exe`, `.dll`

**Tags:** dependencies, binary-analysis, windows

Dependencies is a tool to view dependencies of Windows binaries.

## Tips
Modern Dependency Walker replacement showing DLL imports, API sets and delay loads. Use -chain from the command line to list the full dependency tree and spot missing or hijackable DLLs.

## Usage
DependenciesGui.exe <file> or Dependencies.exe -imports <file>
