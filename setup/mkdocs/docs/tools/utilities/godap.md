# godap

**Category:** Utilities

**Homepage:** <https://github.com/Macmod/godap>

**Vendor:** Macmod

**License:** MIT

**Source:** GitHub Release

**Profiles:** Full (not included in Basic profile)

**Tags:** windows, network-analysis, network

godap is a tool for analyzing Active Directory LDAP data.

## Tips
Interactive LDAP and Active Directory browser in the terminal with search, ACL and Kerberos support. Use it from the network sandbox against a lab domain controller or from a domain joined host.

## Usage
godap <domain controller> -u <user> -p <password>
