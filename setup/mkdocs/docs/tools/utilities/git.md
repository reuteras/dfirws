A fork of Git containing Windows-specific patches.

## Tips
Git for Windows also provides the Unix utilities under Program Files\Git\usr\bin (file.exe, bash, sed) that the verify scripts and several tools rely on. The analysis sandbox is offline, so clone what you need on the host and put it in the readwrite folder.
