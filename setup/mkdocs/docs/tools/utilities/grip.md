# grip

**Category:** Utilities

**Source:** Python

**Profiles:** Full, Basic

**File Extensions:** `.md`

**Tags:** markdown, viewer

Render local readme files before sending off to GitHub.

## Tips
Renders Markdown as GitHub would in a local browser. It uses the GitHub API, so run it in the network sandbox; for offline preview use Obsidian or VS Code.

## Usage
grip README.md
