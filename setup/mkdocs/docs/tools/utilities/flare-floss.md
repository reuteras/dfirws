# Flare-Floss

**Category:** Utilities

**Homepage:** <https://github.com/mandiant/flare-floss>

**Vendor:** mandiant

**License:** Apache-2.0

**Source:** GitHub Release

**Profiles:** Full, Basic

**File Extensions:** `.exe`, `.dll`, `.bin`

**Tags:** malware-analysis, string-extraction, deobfuscation

Flare-Floss is a tool for extracting strings from malware samples.

## Tips
Extracts static, stack, tight and decoded strings from malware. Use --only decoded to focus on obfuscated strings, -j for JSON and --no static to skip plain strings.

## Usage
floss.exe <file>
