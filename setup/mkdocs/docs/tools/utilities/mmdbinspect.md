**License:** Apache-2.0

**Profiles:** Full, Basic

**File Extensions:** `.mmdb`

**Tags:** geolocation, maxmind

Tool for inspecting MaxMind GeoIP2 databases.

## Tips
Looks up IPs in the MaxMind databases from the enrichment data set and prints JSON. Several IPs and databases can be given at once.

## Usage
mmdbinspect -db C:\enrichment\maxmind\GeoLite2-City.mmdb 8.8.8.8
