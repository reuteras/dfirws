# ULogViewer

**Category:** Utilities

**Homepage:** <https://github.com/carina-studio/ULogViewer>

**Vendor:** Carina Studio

**License:** MIT

**Source:** GitHub Release

**Profiles:** Full, Basic

**File Extensions:** `.exe`, `.dll`

**Tags:** log-analysis, viewer

ULogViewer is a log viewer for ULog files.

## Tips
Views and filters many log types (Windows event logs, Android logcat, iOS logs via libimobiledevice, Azure, Apache) with built in profiles. Add a custom profile for new formats.

## Usage
GUI: start from the desktop shortcut and choose a log profile.
