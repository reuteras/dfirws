# RpcView

**Category:** Utilities

**Homepage:** <https://github.com/silverf0x/RpcView>

**Vendor:** Silverf0x

**License:** GPL-3.0

**Source:** GitHub Release

**Profiles:** Full, Basic

**Tags:** network, windows

RpcView is a tool to view RPC endpoints.

## Tips
Enumerates RPC interfaces and endpoints on the running system and decompiles interface definitions. Useful when analysing a driver or service that exposes RPC.

## Usage
GUI: start from the desktop shortcut.
