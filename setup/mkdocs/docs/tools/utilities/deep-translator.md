# deep_translator

**Category:** Utilities

**Source:** Python

**Profiles:** Full, Basic

**Tags:** data-processing

A flexible free and unlimited python tool to translate between different languages in a simple way using multiple translators

## Tips
Translates text via online services, so it needs the network sandbox. Useful for ransom notes and foreign language artifacts.

## Usage
deep-translator -trans google -src auto -tgt en -txt '<text>'
