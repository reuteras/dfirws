# zstd

**Category:** Utilities

**Homepage:** <http://www.zstd.net>

**Vendor:** facebook


**Source:** GitHub Release

**Profiles:** Full, Basic

**File Extensions:** `.zst`

**Tags:** compression, decompression, cli

Zstandard is a fast lossless compression algorithm.

## Tips
Decompress Zstandard archives, used by some EDR exports and package formats. 'zstd -l' lists archive information and -T0 uses all cores.

## Usage
zstd -d file.zst
