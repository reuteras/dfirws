**Tags:** python, data-processing, visualization

Reactive Python notebook stored as plain .py files.

## Tips
Runs in its own environment, not the default venv kernel that JupyterLab uses. Besides marimo[recommended] it has pandas, matplotlib, networkx, pefile, lief, yara-python, dissect, evtx, python-registry and olefile. Do not use --sandbox, it needs the network. Save notebooks in the readwrite folder.

## Usage
marimo edit <notebook.py>

## Sample Commands
- `marimo edit analysis.py`
