**Category:** Utilities

**Profiles:** Full, Basic

**File Extensions:** `.ipynb`

**Tags:** python, data-processing

JupyterLab computational environment

## Tips
Start from the desktop shortcut. Notebooks from jupyter-collection and the dfirws setup are available, and the default venv kernel has the installed DFIR libraries (dissect, pefile, yara, msticpy).

## Usage
jupyter lab --notebook-dir <folder>
