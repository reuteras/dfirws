PowerShell Digital Forensics & Incident Response Scripts.

## Tips
Scripts for live collection and triage on Windows hosts. In the sandbox they are mainly useful for review and for parsing collected output; run the collection scripts on the target system, not in the sandbox.

## Usage
Review the scripts in C:\git\Incident-Response-Powershell and run them on the target host.
