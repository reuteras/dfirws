# docx2txt

**Category:** Files and apps / Office

**Source:** Python

**Profiles:** Full, Basic

**File Extensions:** `.docx`

**Tags:** office, data-extraction

A pure python-based utility to extract text and images from docx files.

## Tips
Dumps the text of a DOCX without opening it in Word. Extract embedded images with -i <dir>.

## Usage
docx2txt.py <file.docx> [output.txt]
