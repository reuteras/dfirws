# XLMMacroDeobfuscator

**Category:** Files and apps / Office

**Source:** Python

**Profiles:** Full, Basic

**File Extensions:** `.xls`, `.xlsm`, `.xlsb`

**Tags:** office, vba, deobfuscation, malware-analysis

xlmdeobfuscator -f <file.xls>

## Tips
Emulates Excel 4.0 (XLM) macros to reveal the hidden commands. --no-ms-excel forces the internal emulator and -x extracts the macros only.

## Usage
xlmdeobfuscator -f <file.xls>
