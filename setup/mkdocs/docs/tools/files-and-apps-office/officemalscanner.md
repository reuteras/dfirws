# OfficeMalScanner

**Category:** Files and apps / Office

**Homepage:** <https://github.com/fboldewin/reconstructer.org>

**Vendor:** fboldewin


**Source:** Git

**Profiles:** Full, Basic

**File Extensions:** `.doc`, `.ppt`, `.xls`

**Tags:** office, vba, malware-analysis

OfficeMalScanner can scan old office documents.

## Tips
Use 'info' to dump VBA macros from legacy .doc and .xls files and 'scan brute debug' to find shellcode, encrypted PE files and embedded OLE objects. For OOXML files (docx, xlsm) use olevba or oledump instead.

## Usage
OfficeMalScanner.exe <file> scan brute
