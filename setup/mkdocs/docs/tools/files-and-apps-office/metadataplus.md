# MetadataPlus

**Category:** Files and apps / Office

**Homepage:** <https://github.com/nccgroup/MetadataPlus>

**Vendor:** nccgroup

**License:** Apache-2.0

**Source:** GitHub Release

**Profiles:** Full, Basic

**File Extensions:** `.exe`, `.dll`, `.doc`, `.docx`, `.xls`, `.xlsx`, `.pdf`, `.jpg`, `.png`

**Tags:** metadata, file-analysis

A tool to use novel locations to extract metadata from Office documents.

## Tips
Extracts metadata from Office documents from places normal tools miss (embedded objects, revisions, template references). Compare with exiftool output.

## Usage
MetadataPlus.exe -f <document>
