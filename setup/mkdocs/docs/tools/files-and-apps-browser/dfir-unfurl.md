# dfir-unfurl

**Category:** Files and apps / Browser

**Source:** Python

**Profiles:** Full, Basic

**Tags:** osint, network, forensics, visualization

unfurl '<url>'

## Tips
Breaks URLs into their parts and decodes embedded timestamps, IDs and tracking data (Google, Twitter, Discord, Snowflake IDs). Start the web UI with unfurl_app for a graph view. Runs in its own venv (venv.ps1 -unfurl).

## Usage
unfurl '<url>'
