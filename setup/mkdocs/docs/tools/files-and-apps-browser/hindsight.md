**Tags:** browser-forensics, browser, artifact-extraction

Browser forensics tool for Google Chrome (and other Chromium-based browsers).

## Tips
Parses Chromium history, downloads, cookies, cache, autofill and more into XLSX, SQLite or JSONL. hindsight_gui starts a local web interface. See forensic-webhistory for Firefox and IE.

## Usage
hindsight.exe -i <Chrome profile folder> -o report
