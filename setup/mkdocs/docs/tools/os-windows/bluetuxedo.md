A tiny tool built to find and fix common misconfigurations in Active Directory-integrated DNS

## Tips
Finds and fixes Active Directory integrated DNS misconfigurations. It needs a domain joined session, so in the sandbox it is mainly for reviewing the checks.

## Usage
Import-Module C:\git\BlueTuxedo\BlueTuxedo.psd1 ; Invoke-BlueTuxedo
