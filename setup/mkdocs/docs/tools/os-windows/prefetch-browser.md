# Prefetch Browser

**Category:** OS / Windows

**Homepage:** <https://kacos2000.github.io/Prefetch-Browser/>

**Vendor:** kacos2000

**License:** MIT

**Source:** GitHub Release

**Profiles:** Full, Basic

**File Extensions:** `.pf`

**Tags:** windows, forensics, filesystem

Prefetch Browser is a tool for analyzing Windows Prefetch files, which can provide valuable information about program execution and system activity.

## Tips
Shows run counts, last run times, volumes and referenced files for each .pf file. Compare with PECmd output from the Zimmerman tools when in doubt.

## Usage
GUI: start from the desktop shortcut and open a Prefetch folder.
