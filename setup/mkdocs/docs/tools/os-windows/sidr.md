Search Index Database Reporter

## Tips
Reports on the Windows Search index (files, emails, activity history) from Windows.edb or the newer SQLite based Windows.db. Copy the database from the image first.

## Usage
sidr <folder containing Windows.edb or Windows.db> -o <output dir>
