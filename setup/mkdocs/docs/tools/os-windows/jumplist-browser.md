Automatic/Custom Destinations & LNK (MS-SHLLINK) Browser

## Tips
Parses Jump Lists and LNK files with full MS-SHLLINK detail (target, volume, MAC address, timestamps). Export to CSV for timelines; JLECmd from the Zimmerman tools is the command line alternative.

## Usage
GUI: start from the desktop shortcut and open AutomaticDestinations or CustomDestinations files.
