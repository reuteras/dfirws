Thumbcache Viewer - Extract Windows Vista, Windows 7, Windows 8, Windows 8.1, and Windows 10 thumbcache database files.

## Tips
Extracts thumbnails from Windows thumbcache databases, which can show images that were later deleted. Map entries to file names with the Windows Search database (Windows.edb).

## Usage
GUI: start from the desktop shortcut and open thumbcache_*.db files.
