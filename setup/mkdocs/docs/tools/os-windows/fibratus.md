## Tips
Install on demand with dfirws-install.ps1 -Fibratus. Captures kernel events (process, file, registry, network) on the sandbox itself with YARA and rule based detections; use it to observe a detonated sample.

## Usage
Fibratus detects, protects, and eradicates advanced adversary tradecraft by scrutinizing and asserting a wide spectrum of system events against a behavior-driven rule engine and YARA memory scanner.
