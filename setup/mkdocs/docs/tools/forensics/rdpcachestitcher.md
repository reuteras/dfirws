# RDPCacheStitcher

**Category:** Forensics

**Homepage:** <https://github.com/BSI-Bund/RdpCacheStitcher>

**Vendor:** BSI-Bund


**Source:** GitHub Release

**Profiles:** Full, Basic

**File Extensions:** `.bmc`, `.bin`

**Tags:** network, forensics, windows

RdpCacheStitcher is a tool for analyzing RDP cache files.

## Tips
Reassembles RDP bitmap cache tiles into screenshots of what the attacker saw over RDP. Extract the tiles with bmc-tools first.

## Usage
GUI: start from the desktop shortcut and open the tiles extracted with bmc-tools.
