Collection of third-party add-on modules for Autopsy — ingest modules, content viewers, report modules, and data source processors.

## Tips
Autopsy must be installed first with dfirws-install.ps1 -Autopsy. In Autopsy use Tools -> Python Plugins to open the plugin directory, copy the module there and restart Autopsy.

## Usage
Copy the wanted module folder from C:\git\autopsy_addon_modules into the Autopsy python_modules directory.
