Redress - A tool for analyzing stripped Go binaries.

## Tips
Recovers package, type and source file information from stripped Go binaries. Use 'Redress.exe packages' and 'Redress.exe types' when Ghidra shows no symbols; GoReSym is the alternative.

## Usage
Redress.exe info <go binary>
