ripgrep is a fast, modern, and user-friendly command-line search tool.

## Tips
Very fast recursive search that skips binaries and gitignored paths by default. Use -a to search binaries, -z for compressed files, --hidden to include hidden files and -l to list matching files only.

## Usage
rg -i '<pattern>' <dir>
