jq for binary formats - tool, language and decoders for working with binary and text formats

## Tips
jq for binary formats: decodes PE, ELF, PCAP, ZIP, PNG, MP4 and many more into a queryable tree. Use -d <format> to force a decoder and jq expressions to extract fields.

## Usage
fq d file.bin
