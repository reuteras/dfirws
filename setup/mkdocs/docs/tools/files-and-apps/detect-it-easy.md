# Detect It Easy

**Category:** Files and apps

**Homepage:** <https://github.com/horsicq/DIE-engine>

**Vendor:** horsicq

**License:** MIT

**Source:** GitHub Release

**Profiles:** Full, Basic

**File Extensions:** `.exe`, `.dll`, `.elf`, `.mach-o`, `.bin`

**Tags:** pe-analysis, file-analysis, packer-detection

Detect It Easy is a tool for identifying file types and detecting packers.

## Tips
Identifies file type, compiler, linker, packer and protector. Use the GUI (die.exe) for entropy graphs and section views, 'diec -a' for a deep scan and -j for JSON.

## Usage
diec <file>
