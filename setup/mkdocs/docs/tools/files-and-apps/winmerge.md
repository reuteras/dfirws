# WinMerge

**Category:** Files and apps

**Homepage:** <https://winmerge.org/>

**Vendor:** Thingamahoochie Software

**License:** [GPL-2.0](https://github.com/WinMerge/winmerge/blob/v2.16.46/LICENSE.md)

**Source:** Winget

**Profiles:** Full, Basic

**Tags:** binary-diffing

WinMerge is a visual file and directory comparison tool that helps you compare files and directories. It is useful for identifying differences between files, merging changes, and synchronizing directories.

## Tips
Install on demand to diff files or whole folders, for example a clean and a suspect copy of a system directory or two versions of a script.

## Usage
dfirws-install.ps1 -WinMerge
