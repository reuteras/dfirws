# magika

**Category:** Files and apps

**Source:** Python

**Profiles:** Full, Basic

**Tags:** file-analysis, ai

A tool to determine the content type of a file with deep learning.

## Tips
Deep learning file type identification that works on renamed or partial files. Use -r for recursive scanning and --json for output; compare with file-magic.py for edge cases.

## Usage
magika <file or dir>
