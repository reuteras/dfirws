# peepdf-3

**Category:** Files and apps / PDF

**Source:** Python

**Profiles:** Full, Basic

**File Extensions:** `.pdf`

**Tags:** pdf, malware-analysis, javascript

A Python 3 tool to explore, analyse, and disassemble PDF files

## Tips
Interactive PDF analysis of objects, streams, JavaScript and suspicious elements. Use -f to force parsing of broken files and -x for XML output; pdfalyzer and pdf-parser.py are the alternatives.

## Usage
peepdf -i <file.pdf>
