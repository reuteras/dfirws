# PE-utils

**Category:** Files and apps / PE

**Homepage:** <https://github.com/hasherezade/pe_utils>

**Vendor:** hasherezade


**Source:** GitHub Release

**Profiles:** Full, Basic

**File Extensions:** `.exe`, `.dll`, `.sys`

**Tags:** pe-analysis, reverse-engineering

A set of small utilities, helpers for PIN tracers.

## Tips
Small helpers from hasherezade: pe_check verifies PE integrity, pe_unmapper converts memory dumps back to raw PE layout and pe_realign fixes headers.

## Usage
pe_check <file>
