**File Extensions:** `.dll`, `.exe`

**Tags:** pe-analysis, conversion

Converts a DLL into EXE

## Tips
Converts a DLL to an EXE with a chosen export as entry point so it can be run or debugged standalone in x64dbg.

## Usage
dll_to_exe <input.dll> <output.exe> [export name]
