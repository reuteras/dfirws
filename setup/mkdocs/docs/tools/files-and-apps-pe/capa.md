capa rules for identifying capabilities in binaries.

## Tips
Identifies capabilities mapped to ATT&CK and MBC in PE, ELF, .NET, shellcode and sandbox reports. Use -vv for evidence, -j for JSON and the capa Explorer extension in Ghidra to navigate to the matches.

## Usage
capa.exe <file>
