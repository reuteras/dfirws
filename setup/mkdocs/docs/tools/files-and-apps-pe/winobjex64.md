WinObjEx64 is an advanced utility that lets you explore the Windows Object Manager namespace.

## Tips
Explore the Windows object manager namespace, drivers, callbacks and more on the running sandbox. Useful when studying a driver or rootkit behaviour after loading it in the sandbox.

## Usage
GUI: start from the desktop shortcut.
