A tool for analyzing PE files

## Tips
Visual PE editor with hex view, imports, resources, rich header and section tables. Useful for fixing dumped PEs (section alignment, imports) before loading them in a disassembler.

## Usage
GUI: start from the desktop shortcut and open a PE file.
