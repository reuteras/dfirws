A tool for studying JavaScript malware.

## Tips
Emulates JScript and WScript malware and logs dropped files, URLs, shell commands and ActiveX use. Use --loglevel debug when a sample exits early, --no-kill to continue past errors and --timeout to give long sleeps a chance.

## Usage
box-js <sample.js> --output-dir <dir>
