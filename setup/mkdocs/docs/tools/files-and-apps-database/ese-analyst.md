This is a set of tools for doing forensics analysis on Microsoft ESE databases.

## Tips
Parses ESE databases such as SRUM (SRUDB.dat), Windows Search (Windows.edb) and WebCacheV01.dat to CSV. Copy the database out of the image first, because ESE files must be writable and may need a repair with esentutl.

## Usage
GUI: start ese2csv from the desktop shortcut and open an ESE database.
