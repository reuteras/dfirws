H2 Database is an open source Java SQL database.

## Tips
Opens H2 database files found in Java applications. Start the console and connect with jdbc:h2:<path without .mv.db>; use DBeaver for a full GUI.

## Usage
java -jar C:\Tools\h2\bin\h2*.jar
