# dsq

**Category:** Files and apps / Database

**Homepage:** <https://github.com/multiprocessio/dsq>

**Vendor:** multiprocessio


**Source:** GitHub Release

**Profiles:** Full, Basic

**File Extensions:** `.json`, `.csv`, `.tsv`, `.parquet`

**Tags:** data-processing, database, json, csv

Commandline tool for running SQL queries against JSON, CSV, Excel, Parquet, and more.

## Tips
Run SQL directly against CSV, JSON, Excel and Parquet files without a database. Combine files by referring to them as {0}, {1} and use -p for a pretty table.

## Usage
dsq file.csv 'SELECT * FROM {} LIMIT 10'
