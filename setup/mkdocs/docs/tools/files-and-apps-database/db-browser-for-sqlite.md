# DB Browser for SQLite

**Category:** Files and apps / Database

**Homepage:** <https://sqlitebrowser.org>

**Vendor:** sqlitebrowser


**Source:** GitHub Release

**Profiles:** Full, Basic

**File Extensions:** `.db`, `.sqlite`, `.sqlite3`

**Tags:** database, sqlite, gui

DB Browser for SQLite is a high quality, visual, open source tool for creating, designing, and editing database files compatible with SQLite.

## Tips
Browse and query SQLite databases from browsers, apps and phones. Open read-only to preserve evidence and use fqlite when you need deleted records.

## Usage
GUI: start from the desktop shortcut and open a .sqlite or .db file.
