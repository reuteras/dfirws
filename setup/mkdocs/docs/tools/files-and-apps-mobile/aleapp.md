# aLEAPP

**Category:** Files and apps / Mobile

**Homepage:** <https://github.com/abrignoni/ALEAPP>

**Vendor:** abrignoni

**License:** MIT

**Source:** GitHub Release

**Profiles:** Full, Basic

**File Extensions:** `.tar`, `.zip`

**Tags:** mobile-forensics, android, artifact-extraction

ALEAPP is a tool for parsing and analyzing Android logs, events, and protobuf files. It can be used to extract artifacts from Android devices and analyze them in a structured way.

## Tips
Accepts tar, zip or extracted folders from Android devices. Use aleappGUI for point and click; reports are HTML under the output folder. Artifact support changes fast, so keep it updated.

## Usage
aleapp.exe -t fs -i <extraction folder> -o <output dir>
