# iLEAPP

**Category:** Files and apps / Mobile

**Homepage:** <https://github.com/abrignoni/iLEAPP>

**Vendor:** abrignoni

**License:** MIT

**Source:** GitHub Release

**Profiles:** Full, Basic

**File Extensions:** `.tar`, `.zip`

**Tags:** mobile-forensics, artifact-extraction

iLEAPP is a tool for parsing and analyzing iOS logs, events, and plists. It can be used to extract artifacts from iOS devices and analyze them in a structured way.

## Tips
Works on iTunes backups, full file system extractions and sysdiagnose archives. Use ileappGUI for point and click and pair with iShutdown for shutdown.log analysis.

## Usage
ileapp.exe -t fs -i <extraction folder> -o <output dir>
