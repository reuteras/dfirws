**Category:** Signatures and information

**License:** MIT

**Profiles:** Full, Basic

**File Extensions:** `.yaml`, `.yml`, `.json`, `.xml`, `.toml`

**Tags:** yaml, data-processing, cli

yq is a portable command-line YAML, JSON, XML, CSV, TOML and properties processor.

## Tips
jq style processing for YAML, JSON, XML, CSV and TOML. Use -o json to convert YAML to JSON and -p xml to read XML, for example exported event logs.

## Usage
yq '.key' file.yaml
