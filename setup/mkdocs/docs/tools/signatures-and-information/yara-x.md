yara-x is a faster and more flexible version of YARA.

## Tips
The Rust rewrite of YARA with better performance and error messages. 'yr check' validates rules, 'yr fmt' formats them and 'yr dump' shows parsed module data.

## Usage
yr scan rules.yar <file or dir>
