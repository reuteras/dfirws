**Tags:** hex-editor, binary-analysis, reverse-engineering

ImHex is a hex editor for binary analysis and pattern language.

## Tips
Hex editor with a pattern language for parsing structures, data inspector, entropy view and diffing. Patterns for common formats are included and can be applied from the pattern store when online.

## Usage
GUI: start from the desktop shortcut and open a file.
