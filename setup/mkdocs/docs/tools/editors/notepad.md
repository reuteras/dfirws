**Tags:** text-editor

Notepad++ is a free source code editor and Notepad replacement that supports several programming languages.

## Tips
Default text editor in the sandbox with the ComparePlus and DSpellCheck plugins. Use Search -> Find in Files for a quick grep across a folder and the Language menu for syntax highlighting.

## Usage
notepad++ <file>
