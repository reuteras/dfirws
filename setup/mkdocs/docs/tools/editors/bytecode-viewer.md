A Java 8+ Jar & Android APK Reverse Engineering Suite (Decompiler, Editor, Debugger & More)

## Tips
Bundles several Java decompilers (Procyon, CFR, FernFlower) plus APK and DEX support. Switch decompiler in the View menu when the output is poor.

## Usage
Start from the desktop shortcut (bcv.bat).
