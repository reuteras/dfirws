Obsidian is a powerful knowledge management and note-taking application that allows you to create and link notes in a graph-based structure.

## Tips
Install on demand for case notes. Create the vault in the readwrite folder so it survives closing the sandbox. Plugins downloaded by dfirws (dataview, kanban, MITRE ATT&CK vault and others) can be installed offline from the Tools folder.

## Usage
dfirws-install.ps1 -Obsidian
